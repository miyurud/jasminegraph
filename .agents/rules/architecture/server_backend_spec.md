# Server & Distributed Backend Specification

**Location**: `src/server/` & `src/backend/`
**Status**: Reverse-Engineered Spec (Brownfield)
**Date**: 2026-09-21

## 1. Overview
These components form the backbone of JasmineGraph's distributed execution model. The `server` component acts as the Master node orchestrator, while the `backend` and `JasmineGraphInstance` components run as daemon processes on the Worker nodes.

## 2. Core Architecture

### 2.1 Master Orchestrator (`JasmineGraphServer.h`)
* **Role**: The central coordinator. It spins up workers (`startRemoteWorkers`), assigns partitions to them, and maintains the global state of the cluster.
* **Communication**: Uses custom TCP/IP socket protocols to send commands to workers (e.g., `sendQueryPlan`, `initiateMerge`).
* **State Tracking**: Uses `hostPlaceMap` and `workerPortsMap` to route tasks to the correct physical machine.

### 2.2 Worker Daemons (`JasmineGraphInstance.h`, `JasmineGraphBackend.h`)
* **Role**: These processes run continuously on the worker machines. They listen on designated ports for instructions from the Master.
* **File Transfer**: Uses `JasmineGraphInstanceFileTransferService` to receive partition files generated by the Master's `MetisPartitioner`.
* **Execution**: When a query plan is received, it triggers local executors (like `IntraPartitionParallelExecutor`) and sends the results back.

## 3. Implicit Contracts & Constraints (Important for AI Agents)
* **Non-Blocking Network Calls**: The socket communication in `JasmineGraphServer` is synchronous in many places. AI agents must be extremely careful not to introduce long-running compute loops on the main network threads, as it will cause cluster-wide timeouts.
* **Port Management**: Workers use distinct ports for control commands versus bulk data transfer (`workerPortsMap` vs `workerDataPortsMap`). Agents must not mix these up.
* **Stateless Workers**: Workers should generally be treated as stateless compute engines. The definitive truth of the cluster lives in the Master's `MetaDB`.
