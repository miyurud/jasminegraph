## Governance & Human Approval Gate

1.  **Human Gate**: All code generated by AI coding agents requires mandatory review and approval by repository maintainers before merge. Auto-merging is strictly prohibited.
2.  **Maintainer Contact**: Primary maintainer is **@miyurud** and the JasmineGraph team.
3.  **Exception Requests**: If an agent must exceed the 150–200 LOC per-task limit or introduce third-party components, open a GitHub issue with the `[Exception Request]` tag to receive maintainer confirmation.
